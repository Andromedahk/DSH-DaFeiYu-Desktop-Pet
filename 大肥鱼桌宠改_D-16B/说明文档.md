# DSH 余额宠物 (v10)

一个能贴在桌面上的小挂件：角色举着一块**纯黑屏幕**的平板，屏幕上实时显示你的 DSH（DeepSeek）余额。
余额每下降 **0.01 元**，角色就红闪一下 + 轻微震动，同时**播放一次打击音效**，
头顶弹出红色的 **-0.01** 向上飘并渐隐（数字和屏幕文字会**跟着角色一起抖**）。
**余额上升（充值）时，屏幕右侧会掉下一盆米饭**，把它拖到角色身上才会入账（见第二节）。

```
DSH宠物/
├── 先看这里（快速开始）.md   ← 给收件人看的说明
├── 启动DSH余额宠物.vbs      ← 双击启动（静默、无黑框）
├── 启动（调试窗口）.cmd       ← 出问题时用这个启动，能看到报错
├── dsh_pet.ps1              主程序（窗口 / 动画 / 音效 / 余额轮询 / 右键菜单）
├── sprite.png               处理好的角色贴图（黑屏原样保留，透明通道保留）
├── rice.png                 充值用的米饭盆素材（本身就是透明底）
├── make_sprite.ps1          从原图重新生成 sprite.png，并自动量出黑屏四角
├── hit.mp3                  打击音效（可换成你自己的，见第六节）
├── feed.mp3                 把米饭喂给角色时的音效
├── state.ini                自动生成：记住尺寸、音量、开关
├── apikey.txt               只有设置过 Key 才会出现
└── pet.log                  自动生成：每次请求与音效状态都记在这里
```

## 一、启动

1. 双击 **`启动DSH余额宠物.vbs`**。
2. 角色出现在**屏幕左下角**（默认 **大杯 = 454×454 像素**），平板上几秒后显示余额。
3. 开机自启：`Win + R` 输入 `shell:startup`，把 vbs 的快捷方式丢进去。

前提：**Windows PowerShell 5.1**（系统自带）+ **Node.js**（建议保留，理由见下）。
API Key 会自动读取 `%USERPROFILE%\.dsh\.credentials.yaml` 里已有的 `DEEPSEEK_API_KEY`；
**读不到时会弹出输入框让你填**（分享给别人时对方就用这个入口）。

> 为什么建议保留 Node：取余额走两条路 —— 先试 .NET，失败再改用 Node。
> 有些机器上 .NET 拿不到 TLS 凭据（`SEC_E_NO_CREDENTIALS`），这时就只剩 Node 这一条路。
> 两条路的结果都会写进 `pet.log`，所以出问题时先看日志就能知道走了哪条。

## 二、操作

| 操作 | 效果 |
| --- | --- |
| **左键按住拖动** | 只有在按住左键时才能移动；**一松开就自动吸附回屏幕左下角**（0.16 秒缓动） |
| **左键按住米饭盆拖动** | 把盆拖到角色身上（含头饰）就会"喂"给她：盆消失、头顶冒像素爱心、**充值金额一次性入账** |
| 右键 | 菜单，见下 |
| 角色以外的透明区域 | 鼠标穿透，不挡你点桌面 / 其他窗口 |
| 双击托盘图标 | 手动触发一次扣费动画（含音效） |

### 右键菜单

菜单分成几组（灰色的「测试 / 显示」是小标题）：

| 项目 | 说明 |
| --- | --- |
| **立即刷新余额** | 马上请求一次，并让平板**直接跳到最新余额**，结果写进 `pet.log` |
| 测试一次扣费效果 | **纯演示**：播一次扣费动画（红闪 + 飘字 + 音效），不改真实余额 |
| **测试充值动画 ▸** | 子菜单：`模拟充值 3 元（掉米饭盆）` 或「自定义…」。**不花钱**，但会走完整的充值流程（改本地余额 → 掉盆 → 拖给她 → 入账）。测完点一次「立即刷新余额」就回到真实值 |
| **演示连续扣费 ▸** | 子菜单：`-0.05 / -0.1 / -0.2 / -0.5 / -1` 或「自定义…」。选多少就连续扣多少次（0.2 秒一次），**节奏和真实扣费完全一样** |
| **尺寸 ▸** | `中杯 340 px` / `大杯 454 px`（默认）/ `超大杯 624 px` / 「自定义…」（像素，正方形，1:1） |
| **声音 ▸** | `开启声音` 开关；`音量大小` 五档 `0 / 25 / 50 / 75 / 100 %`（0 % 就是静音）；「自定义…」填 0–100。**改完立刻生效并记住**，不影响系统音量 |
| 设置 API Key | 换 Key（写进 `apikey.txt`，留空则不修改） |
| 退出 | 关闭 |

### 充值：掉米饭盆

云端余额**上升**时（有人给你充了钱），程序不会直接改屏幕上的数字，而是：

1. 从**屏幕右边缘**丢下一盆米饭，让它自由落体 + 弹跳（弹几次取决于掉落高度，最多 3 次）；
2. 屏幕数字**保持不动**，等待你去拿；
3. 用左键**把盆拖到角色身上**（碰到头发/头饰也算）→ 盆消失、头顶冒像素爱心、
   **这笔充值一次性加到屏幕上**，同时飘一个**绿色**的 `+x.xx`（和扣血的红色数字区分开）。
4. **不拖就永远不加。** 盆可以一直躺在屏幕底部；也可以同时有多个盆（一笔充值一个盆），
   它们彼此有碰撞体积、不会叠在一起，逐个拖给她就逐个入账。

> 看不到盆？确认是**余额上升**（充值）而不是下降；只在两次轮询之间"涨了又被花掉"（净额没变）
> 是不会掉盆的，这是刻意的。

### 两种刷新的区别（重要）

* **后台自动轮询**（默认每 2 秒）：余额下降时**一分钱一分钱地扣**，每次扣费都完整播一遍动画 + 音效。
* **右键「立即刷新余额」**：**立刻对齐到最新余额**（不补播动画）。
  想看连续动画就用「演示连续扣费」。

## 三点五、扣费的节奏（v10 定稿）

**步长固定为 0.01 元，不再可调。** 这是刻意的设计：

* **0.01 是接口报数的最小单位**，所以永远不会有"凑不满一格的零头"，
  也就从根上排除了"数字动了但没播动画"这类问题。
* 每次扣费之间**间隔 0.2 秒**，每次都完整播放红闪 + 震动 + 音效 + 飘字。
  间隔短了之后，飘出的数字会**像连击那样向上错开排成一条串**，不会叠在一起看不清。

**规则**：云端余额一有变化，就把差额换算成 **N 个 0.01**，然后一个一个地扣。

> 例：余额从 30.00 变成 29.95（少了 0.05）
> → 连续扣 5 次：`-0.01`、`-0.01`、`-0.01`、`-0.01`、`-0.01`，
> 屏幕数字 30.00 → 29.99 → 29.98 → 29.97 → 29.96 → **29.95**，
> 每一次都有完整的红闪 + 震动 + 音效 + 飘字，间隔 0.2 秒，五个 `-0.01` 依次向上串成一条。

**数字绝不会在没动画的情况下变化**：数字只在扣费那一帧变化，而且一次只变 0.01。

**"实时"指的是延迟小**：服务器那边余额一变，下一次轮询（默认 2 秒）就把它换算成扣费次数，
**第一次扣费当帧就会弹出**，不会压着等下一轮。

> 大额跳变的保护：一次最多排队 40 次（0.40 元），避免云端一次性跳很多时动画播上好几分钟。
> 剩下的部分会在后续轮询里继续补完。

## 四、它是怎么工作的

* **余额来源**：`GET https://api.deepseek.com/user/balance` → `balance_infos[].total_balance`（CNY）。
* **两个数值**：
  * `真实余额`：接口刚读到的值；
  * `屏显余额`：平板上打印的数字，**只在扣费那一帧变化，且一次只变 0.01**。
  账面基准与屏显余额成对维护，欠款 = 账面基准 − 真实余额，
  每次读数都**重新推导**，所以任何时刻到达的数据都不会让数字失同步。
* **逐分结算**：欠款换算成 N 次 0.01 的扣费，一次一个、间隔 0.2 秒，每次都完整播动画 + 音效。
* **轮询与延迟**：默认每 2 秒问一次。取数在**后台线程**做（避免卡住界面），拿到结果后**当帧结算**，
  所以从服务器数据变化到你看到扣费，延迟≈轮询间隔，不会再额外等。
* **"立即刷新余额"= 立即对齐**：屏显直接等于真实余额（不足一格的零头也抹平），并清掉演示偏移。
* **"测试一次扣费"是纯显示**：只把**打印出来的数字**往下挪（一个显示偏移），不碰真实余额、也不碰步长基准。
  所以按几次之后再「立即刷新余额」，数字会干净地回到真实值。
  **偏移没有上限**（早期版本封顶 10 个步长，导致连点 10 次后数字冻结），只在打印时钳到 0 不为负；
  一旦发生真实消耗，偏移自动清零。
* **红闪**：角色贴图预处理为一张纯红剪影（保留 alpha）。**叠加强度随尺寸自适应**
  （小尺寸约 64%，大尺寸约 30%），避免大尺寸时糊成一团红。
* **震动**：阻尼正弦抖动（约 ±8px 峰值，0.55 秒衰减），**固定像素幅度**而不是按比例缩放
  ——按比例缩放在小尺寸下会被取整成 0，等于不抖。同时生效的受伤层最多 3 个，并且总位移有硬上限，
  避免连点时把角色甩出屏幕。抖动偏移同时施加到屏幕文字和飘字上，三者严格同步。
* **音效**：走 Win32 **MCI** 接口，预先开 4 个别名槽位。每次飘字弹出就找一个空闲槽位播放，
  **互不打断、可以叠着响**。为避免目录名里的中文被编码破坏，程序先切到音效所在目录再用文件名打开。
  音量按 `setaudio ... volume to N*10` 下发，右键菜单里改**立刻生效**；喂食用的是另一个音效池（`feed.mp3`）。
* **屏幕**：黑色内屏保持原样不涂任何颜色，只画「DSH 余额」和数字（浅色字 + 深色描边），
  用三点映射贴合到屏幕四边形上（四角由 `make_sprite.ps1` 自动量出）。
  **余额位数变多时，数字会自动缩小以留在屏幕内**（"DSH 余额"和 ￥ 符号大小不变）；
  两位数以内就是原来的大小，所以平常看不出区别。
* **尺寸**：菜单里的中杯 / 大杯 / 超大杯 = **340 / 454 / 624 像素**（正方形，1:1），
  「自定义」直接填像素。**像素是存储单位**（厘米不是固定的像素数，换显示器就会变），
  旧的 `DSHPET_CM` 仍然被读取，会按当前显示器 DPI 换算成像素。
* **充值**：云端余额上升 → 差额记成"待领额度" + 掉一个米饭盆；只有把盆拖到角色身上才
  一次性入账（见第二节）。盆是屏幕坐标的自由落体（重力 2100 px/s²、回弹系数 0.5、
  落地后弹 3 次，重新从高处扔下会按高度重算弹跳次数）。
* **窗口**：WinForms 无边框 + 分层窗口（逐像素 alpha），`WM_NCHITTEST` 对透明像素返回 `HTTRANSPARENT` 实现穿透点击。
  为了让盆能从**真正的屏幕右边缘**掉下来，窗口从创建起就是**满屏尺寸**（永不改变），
  角色按偏移画在左下角——改窗口尺寸会让角色闪一下，所以这条路被彻底堵死了。
* **流畅度**：每帧只重画"这一帧变过的那一块"，屏幕推送也走常驻缓冲区，不再整屏重建。
  角色不动的时候（例如只有米饭盆在下落）完全不重绘她那一块，鼠标拖动也只在动画帧里画一次。

## 五、分享给别人（或公开分享）

**要发整个文件夹，不能只发启动程序。** 启动器只是个外壳，真正干活的是同目录下的
`dsh_pet.ps1` + `sprite.png` + `rice.png` + `hit.mp3` + `feed.mp3`；少一个都会缺图或缺音效。

**如果你要转发/公开这一份，先删掉这三样**（它们只属于你本人）：

| 文件 | 为什么不能发 |
| --- | --- |
| `apikey.txt` | **里面是你的 API Key** |
| `pet.log` / `error.log` | 运行日志，含你的余额数值与路径 |
| `state.ini` | 你调过的尺寸与音量，对方不需要继承 |

脚本里**没有写死任何绝对路径或用户名**（用的是脚本自身所在目录、`%USERPROFILE%`），
所以对方解压到任何目录都能直接用。

对方第一次启动时会**弹出输入框让他填自己的 API Key**（因为他多半没装 DSH，
程序找不到 `.dsh\.credentials.yaml`）；取消也能用，只是先离线显示 `--`，之后右键菜单随时补填。

> 本仓库/本包只包含**源代码和素材**，成品 zip 请通过 GitHub 的 **Releases** 发布，
> 不要塞进代码仓库（每改一次就多一份 1.5MB，历史会越来越臃肿）。

# 换立绘：重新生成贴图，并打印黑屏四角坐标

## 七、自检与排错

```powershell
# 渲染一帧到 selftest.png，并打印尺寸/账本状态
powershell -ExecutionPolicy Bypass -File .\dsh_pet.ps1 --selftest

# 真实开窗跑 2.5 秒：打印抖动偏移、文字落点，并验证刷新语义
powershell -ExecutionPolicy Bypass -File .\dsh_pet.ps1 --shot

# 喂一串模拟余额，检查"按格扣费 + 拆格补扣 + 演示不冻结"
powershell -ExecutionPolicy Bypass -File .\dsh_pet.ps1 --simchain

# 充值链路全量自检（离线）：冻结 → 掉盆 → 拖给她 → 入账
powershell -ExecutionPolicy Bypass -File .\dsh_pet.ps1 --topup
```
`--topup` 结尾应有 **15 条 `verdict: OK`**（含音量、动画收尾、饭盆不擦掉角色、
未领取充值不入账、数字排版 5 类检查）。
这些自检都**不会改你的 `state.ini`**（尺寸/音量不会被测试改掉）。

`--simchain` 会输出类似：
```
step=0.01 per cue, 0.2s apart   (one cent per animation)
sizes: 中杯=340x340 大杯=454x454 超大杯=624x624 custom(700)= 700x700
menu : renderer=PetMenuRenderer font=Microsoft YaHei UI items=13 sizes=[...] sound=[...]

the reported case: a 0.05 drop becomes FIVE animations
  reset -> printed 30.00  (bookedAt 30.00)
  server -> 29.95 : owed 0.05  -> printed still 30.00     <- 冻结，等动画
    +0.3s -> printed 29.98  cue (none)  owed 0.03
    +0.3s -> printed 29.97  cue (none)  owed 0.02
    ...
  settled -> printed 29.95  (30.00 - 0.05 = 29.95, 5 animations)

read 30.00 -> printed 30.00 -> after cues 30.00
read 29.99 -> printed 30.00 -> after cues 29.99           <- 每格都补扣到位
```

`--shot` 会输出类似：
```
shown after auto poll     = 28.49
shown after refresh now   = 28.49   (must equal the live balance)
shown after 3 test cues   = 28.40
shown after refresh again = 28.49   <- back to the live balance, no drift
shake2: shake=(8.0,8.0) screenText=(435.3,341.7) floater=(288,165)
```

**角色不出现 / 一闪而过**
用 `启动（调试窗口）.cmd`，再看 `error.log` 与 `pet.log`。

**没有声音**
看 `pet.log`：正常会有 `sound ready: ... volume=80`。
* `sound pool failed` → 音效文件缺失或被占用。
* `sound: nothing played` → 系统 MCI 打不开该 mp3，换一个试试。
* 静音：右键菜单 → `声音` → `开启声音` 取消勾选，或把音量调到 0 %；
  也可以设 `DSHPET_SOUND=0`，或删掉 `hit.mp3`。

**掉了米饭盆但数字不变**
这是**设计如此**：必须用左键把盆**拖到角色身上**才会入账（见第二节）。
如果盆根本拖不动，看 `pet.log` 里有没有 `bowl landing:` / `rice grab` 记录。

**屏幕一直显示 `--`**
看 `pet.log`：`node not found` → 装 Node.js 或设 `DSHPET_NODE`；
`HTTP 401` → Key 不对，右键「设置 API Key」换一个。屏幕角落出现**红点** = 当前离线。

**红闪太强/太弱**
`dsh_pet.ps1` 里 `double maxTint = Math.Max(0.30, 0.64 - _scale * 0.75);` 改这两个数即可。

## 八、改脚本前必读

这些 `.ps1` 文件是**故意写成纯 ASCII 的**（界面上的中文用 C# `\uXXXX` 转义）。
因为 Windows PowerShell 5.1 在没有 BOM 时按 ANSI 读取脚本，直接写中文会乱码甚至解析失败。
要改脚本请**只写英文**，中文用 `\uXXXX` 转义；改 `说明文档.md` 这类文件请用支持 UTF-8 的编辑器。

## 九、想微调节奏

步长固定 0.01、间隔固定 0.2 秒（刻意不可调，理由见第三点五节）。
真要改，只能改源码常量（在 `dsh_pet.ps1` 顶部附近，**只写英文**）：

| 常量 | 默认 | 含义 |
| --- | --- | --- |
| `StepYuan = 0.01` | 0.01 | 每次扣多少 |
| `CueGapSec = 0.2` | 0.2 | 两次扣费之间的间隔 |
| `MaxCuesPerPoll = 40` | 40 | 单次轮询最多排队多少次，防云端大跳变时动画播太久 |

轮询快慢用环境变量 `DSHPET_POLL_MS`（默认 2000 毫秒，最小 1000）。
